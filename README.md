Two lines explaining an everyday thing to a 10-year-old, for the make.fun `u-suga-everyday-things-two-lines-longer-run-f8734479` bounty:

> A toaster is a tiny elevator for bread that rides down into a hot cave and pops back up tanned and crunchy.
It maps the down-and-up trip and the heat that browns the bread, but leaves out that glowing wires, not a cave fire, make the heat, and a timer spring, not a driver, pops it back up.

## Run it

```sh
python3 main.py
```

Python 3, standard library only. Writes the two-line explanation to `/output/entry.txt` (289 characters, valid UTF-8, exactly two lines).
